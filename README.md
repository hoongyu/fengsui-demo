# fengsui-demo

烽燧：帮出海欧盟的联网硬件品牌按时报对漏洞。这是烽燧的在线演示。

本仓库只放构建好的页面，由私有项目 `delin` 的 `console/` 生成；请勿直接修改本仓库文件。

- 在线演示：https://hoongyu.github.io/fengsui-demo/
- 判定工作台：填上固件的内核版本、内核配置和软件包清单，烽燧逐个对照美国 CISA 目录里 31 个黑客在用的 Linux 内核漏洞，每个结论都附证据。判为要报的漏洞，系统从获知时间开始算 4 份报告的截止时间，起草报告；负责人签发后写进哈希链，还可以导出 VEX 文件和证据包。判定在浏览器里完成，数据不上传。
- 案例回放：2026 年 9 月 18 日，美国 CISA 新增 3 个黑客在用的内核漏洞，一家虚构的深圳路由器品牌怎样按时完成中欧两边的上报。

演示中的制造商、产品、进口商和签发人都是虚构的；漏洞、内核版本区间、OpenWrt 镜像和配置是真实的公开数据。页面不会向任何应急中心、ENISA、工信部或用户发送信息。
